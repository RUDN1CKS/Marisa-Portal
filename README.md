# Marisa Portal ❤️

A private couple-style messaging web app with:
- 💬 Chat system
- 📝 Shared to-do list
- 🤖 Malana AI (simple assistant)
- 🎮 Tic Tac Toe game
- 📱 Mobile-friendly UI

## How to run
Just open index.html in a browser or deploy with GitHub Pages.

## Files
- index.html → structure
- style.css → design
- app.js → functionality
